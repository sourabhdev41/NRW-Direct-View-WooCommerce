# NRW Direct View WooCommerce

Open WooCommerce downloadable product files directly in a new tab using the original file URL instead of WooCommerce protected redirect links.

## Features

- Opens downloadable products directly
- Uses original download file URL
- Opens downloads in a new browser tab
- Lightweight and fast
- No settings required
- Works automatically after activation

## How It Works

Normally, WooCommerce uses protected download URLs like:

```txt
yourwebsite.com/?download_file=123
```

This plugin replaces them with the actual file URL you added inside the WooCommerce product download section.

Example:

```txt
https://example.com/files/product.zip
```

The file automatically opens in a new tab.
